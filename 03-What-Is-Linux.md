# 🖥️ What Is An Operating System?

An Operating System (OS) manages:

- Hardware
- Memory
- Storage
- Applications

Examples:

- Windows
- Linux
- macOS

- EC2
- Containers
- Kubernetes
- Web Servers
- Databases
