# 🧠 How To Think Like An Engineer

## 🎯 Learning Objectives

- Understand systems thinking
- Understand computers, servers and VMs
- Learn to ask better questions

---

# 🖥️ Computer

A computer contains:

- CPU
- RAM
- Storage
- Operating System

---

# ⚙️ Server

A server is a computer that provides a service.

```text
Computer + Service = Server
```

---

# 🏢 Virtual Machine

A VM is a software-based computer running on another physical computer.

---

# 🏠 Apartment Analogy

Physical Building = Physical Server

Apartment = Virtual Machine

Each apartment operates independently.

---

# 👨‍🔧 Engineer Thinking

Beginners ask:

> What is this?

Engineers ask:

> What does this do?

> Who uses it?

> What happens if it fails?



## Why Should You Care?

Technology changes constantly.

Engineering thinking does not.

---

## Simple Explanation

Engineers focus on:

- Understanding systems
- Solving problems
- Making decisions based on evidence

---

## Real World Analogy

A mechanic does not guess.

A mechanic investigates.

Engineers work the same way.

---

## Engineering Mindset

When encountering a problem ask:

1. What is broken?
2. What should happen?
3. What changed?
4. What evidence exists?

---

## Production Example

Instead of:

```text
Restart Everything
```

Think:

```text
Investigate
Collect Evidence
Test Assumptions
Apply Fix
```

---

## Key Takeaways

✅ Engineers investigate before acting.

✅ Evidence is more valuable than assumptions.

✅ Good questions lead to good solutions.

---

## 🧠 Solutionist Thinking

A Solutionist focuses on understanding before acting.

Never guess.

Investigate.
